# 交接说明（QWB / QuantumWorkbench，2026-10-25）

给接手的人：这本文件回答三个问题——**现在系统能做什么、验证到了什么程度、下一步该从哪里下手**。
更细的记账在 `docs/status.yaml`（68 个 WP 的状态），缺什么外部输入在 `docs/unblock.md`，
踩过的坑在 `docs/choices.md`（二十四节，按时间顺序）。

## 一、一句话现状

引擎本体已经是一条**能跑通且自己会验自己**的链路：
基组数据 → 一/二电子积分（任意角动量）→ XC（LDA + PBE）→ SCF（DIIS + 检查点）→
性质（偶极、布居）→ 解析梯度（任意角动量）→ BFGS 几何优化 → 数值 Hessian / 简正模 / ZPE →
CLI（`qwb run` / `replay` / `data verify` / `inspect`），并且**每次改动都会被 19 项 gate 拦住**。

没做完的不是代码，主要是**缺一份可引用的外部数据**（见 `docs/unblock.md`）。

## 三、这一阶段抓到的五个真 bug（按危害排序）

1. **Boys 函数在大 `T` 下整体失效**（`docs/choices.md` §十三）。向下递推固定 padding 40，种子误差被放大
   `(2x)^top/(2top−1)!!` 倍，`x=33.9` 时 `F₀` 相对误差 **8.6e-2**。后果：O 的 1s（ζ≈130）相关的积分全错，
   水的 HF 能量差 **2.36 Ha**。这个缺口躲过了此前所有内部一致性检查——因为那些检查的参照值
   调用的是同一个错的 `F₀`。**教训**：自洽检验证明不了共用原语正确，原语必须另有外部锚点。
2. **Becke 分区符号反了**（§十八）。`½(1 + p^k)` 写成标准式 `½(1 − p^k)` 的补，于是「离谁近就不归谁」，
   分子网格在 O 核 0.1 bohr 内积出**精确的零**。三条既有网格测试（`Σw=4π`、单原子分区=1、平滑高斯）
   在错的情况下全部通过。**教训**：求积类改动必须有一条**电子数**测试（被核心主导）。
3. **闭壳层 Fock 用了 `H + 2J − K`**（§十）。`P` 已是自旋求和，于是 2e 贡献翻倍，HF 能量差 1.4 Ha。
4. **核吸引的 Hermite 展开对角动量处理错**（I-02 记账）。角动量直接相加、丢掉 `(P−A)/(P−B)`，
   s 型看不出来（所以 H₂ 一直精确），p/d 全错。
5. **2e 的球谐变换用错了 stride**（§二十一附近）。用输入的线性偏移配输出的 stride，d 壳层必越界。

共同点值得记：**前四个都是「某个共享原语错了，而所有用到它的测试都跟着错」**。真正抓住它们的
不是断言，而是「把一个量与另一条独立路径比」——六分项差分、电子数、外部能量、点电荷极限。

## 四、明确没做的（不要误以为有）

* **KS 分支的解析梯度缺一项**：KC 的 `E_xc(P)` 还有一个「显式基组运动项」
  `∫v_xc·(∂ρ/∂R)|_P固定`（`docs/choices.md` §二十四）。实测差 1.42e-1，已记为 known-gap。
  优化器因此只对 HF 用解析梯度，KS 退回数值梯度（慢约 18 倍）。
* **IR 强度与热化学**（S、G）未做；简正模与 ZPE 有。
* **ECP**（I-05）未做；`LANL2DZ`/`def2-ECP` 数据也没有 → T5 未开始。
* **B88/LYP 与 hybrid**（D-11/D-12）未做 → T6（B3LYP）未开始。
* **Python 侧 `qwb-studio`**（P-01..P-06、P-09、P-10）未开始；`pydantic` 不在环境里。
* 2e 解析梯度按 `n_cart⁴` 直算，CH₄ 就要分钟级 → G-03 的完整三分子只能 `#[ignore]`。

## 五、下一步（如果只做三件事）

1. **补 KS 的显式 XC 项**（半天量级）。`evaluate_xc` 多返回势值，构造
   `V'_{μν} = Σ_p w_p v(r_p)(∂φ_μφ_ν + φ_μ∂φ_ν)`，取 `Tr(P·V')`。判据现成：
   `cargo test -p qwb-engine --test g01_analytic_pbe -- --ignored` 现在是 1.42e-1，修好后去掉 `#[ignore]`。
   收益：PBE 体系的几何优化/Hessian 不用再退回数值梯度。
2. **补一份外部数据**（`docs/unblock.md` 第二节）。优先级最高的是 **def2-TZVP 基组文件**——
   它是 T3/G-02 那条「键长差 < 0.01 Å」的唯一卡点，其余都已就绪。
3. **2e 解析梯度分块/预筛**。让 G-03 的完整三分子优化进 gate（现在只有冒烟版），
   也为 def2-SVP 的梯度实用化铺路。

```powershell

```

慢的测试都带 `#[ignore]`，实测数字写在它们的文档注释与账本里——**不是没跑，是没放进 gate**。
