DA-05 done: SMD nonpolar parameters transcribed from MNSOL with provenance

The eight solvents already carried a shell 'smd:' block; the parameters it
lacked are now filled from the Minnesota Solvation Database row
[n20, n25, alpha, beta, gamma, epsilon, phi^2, psi^2], with the formula
source being Marenich-Cramer-Truhlar JPCA 2009 (doi 10.1021/jp810292n):
gamma, phi^2, psi^2, Abraham alpha/beta, n20/n25 and
nonpolar_terms_available.

Cross-check that this is the same table our solvent files already use: the
epsilon column matches our stored epsilons value for value (78.355, 32.613,
24.852, 35.688, 46.826, 4.7113, 2.3741, 7.4257) and n20 matches our
refractive_index. Water's gamma/phi/psi are -1 placeholders in MNSOL (SMD
treats water through the separate CDS path), so those stay null and
nonpolar_terms_available stays false.

Units: MNSOL's gamma is cal/(mol*Angstrom^2) (methanol 31.77 => 22.07 mN/m),
so the K1 field is renamed from gamma_mn_per_m to
gamma_cal_per_mol_angstrom2 and stores the published unit unconverted.

Gotcha: the first generator version split the file at 'smd:' and re-appended,
which cut scale and atomic_radii; qwb data verify caught it with
'missing field atomic_radii'. The generator now replaces the existing block in
place and --check compares semantically (stamping reorders YAML).

DATA_LICENSES regenerated, registry 0.13.0 -> 0.14.0 with eight new pins.
